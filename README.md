# DRT · 재고관리

리사이클링팀 재고관리 시스템 (배터리 리사이클링 로트 추적). `site/` 폴더가 GitHub Pages로 배포되는 실제 사이트예요.

- `site/index.html` — 앱 전체 (React + htm, 외부 CDN 없이 자체 포함)
- `site/data.json` — 팀 공유 데이터. 이 파일만 바뀌면 사이트를 새로 빌드하지 않아도 열려있는 화면에 20초 안에 자동 반영돼요.

## 데이터 갱신 방법

1. 사이트에서 설정(⚙️) → PIN으로 잠금 해제 → 재고 입력/수정
2. 헤더의 "팀 공유용 내보내기"로 JSON 파일을 받음
3. 그 파일 내용을 `site/data.json`에 반영해서 커밋·푸시 (또는 Claude에게 전달)
